# SOLPRINT

**Autonomous On-Chain Trading Intelligence**

SOLPRINT is a self-hosted quantitative trading platform designed
for Solana memecoin markets, combining on-chain intelligence,
wallet analytics and automated trading strategies.

## Planned Features

- Real-time wallet discovery and monitoring
- Token security and liquidity analysis
- Quantitative trade evaluation
- Historical backtesting and paper trading
- Automated execution and risk management
- Real-time trading dashboard

## Technology

Rust, Tokio, Axum, React, TypeScript, PostgreSQL and Docker.

## Development Status

SOLPRINT is currently in early development.
Live trading is not yet supported.
